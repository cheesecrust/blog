
## 키보드 접근성

키보드 접근성이란 마우스 없이 **키보드만으로** 웹사이트의 모든 기능을 사용할 수 있도록 하는 것입니다.
마우스를 다루는 것이 어렵거나 선호하지 않으시는 분들이 대상입니다.
이의 보조 도구로는 스크린 리더 또한 있습니다.

## komi-2539 mcp 아이템 접근성

이 pr 은 mcp card 가 tab 이 가능하도록 하고, 포커싱 시 무엇을 포커싱했는지 알도록

`<button>` 의 경우에 기본적으로 tab 으로 focus 가 가능하기 때문에 이를 제외하기 위해서 `tabIndex={-1}` 을 추가하였습니다. 
`<div>` 의 경우에는 이 기능이 안 켜져 있어서 `tabIndex={0}` 으로 순서 안에 넣어 주었습니다.

tab 의 포커스 순서는 dom 트리 기준으로 위에서 부터 아래로 차례 차례 갑니다.

## komi-2540 페이지 네이션 번호에 접근성 추가

`span` 은 키보드 포커스가 불가능해서 `button` 으로 변경
- 이때 tabIndex 를 추가하지 않고 button 으로 바꾼 이유는 다른 부수적인, onKeyDown, 스크린 리더에게 전달해 주기 위한 속성들을 추가해야 하기 때문에 간단한 button 으로 변경했습니다.

페이지가 넘어가는 경우 focus 가 해당 페이지의 첫 mcp item 으로 가는 것이 자연스럽기 때문에 이렇게 구현

**`isLoading`만 있으면:**

- React Query의 `keepPreviousData` 옵션 때문에 캐시된 페이지 재방문 시 `isLoading`이 `false → false`로 변하지 않아 effect가 실행되지 않음

**`list`만 있으면:**

- 로딩 시작 시 `list`가 빈 배열로 바뀌면서 effect가 실행됨
- 이때 카드가 아직 없어서 포커스 실패 + `isPageChanged`가 `false`로 리셋
- 실제 데이터 로드 후에는 플래그가 이미 꺼져서 포커스가 안 잡힘

**둘 다 있으면:**

- `!isLoading` 조건으로 로딩 중에는 건너뛰고
- `list` 변경으로 캐시된 경우에도 새 데이터 도착 시 effect가 실행됨

list 가 바뀌었는데 로딩중이라면 안하도록 하기 위해서 isLoading 을 넣음

aria-disabled 는 비활성 상태라고 알려주는...
