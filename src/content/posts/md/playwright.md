## 마크다운 편집 결과

### 서론

이 문서는 마크다운 편집 규칙을 설명합니다. 목표는 주어진 글을 읽기 쉽고 구조적으로 만드는 것입니다. 핵심은 **가독성**을 높이는 것입니다.

### 마크다운 규칙

다음은 적용할 마크다운 규칙입니다.

- 적절한 곳에 `##` 소제목 추가
- 중요한 키워드는 **굵게**
- 목록이 적절한 곳은 `-` 리스트 사용
- 코드가 있으면 ``` 코드블록 사용
- 원본 내용과 의미는 그대로 유지
- 마크다운 문법만 추가하고, 내용 자체를 바꾸지 마
- frontmatter(---로 시작하는 부분)는 출력하지 마, 본문만 출력해

### 코드 예시

다음은 코드 블록의 예시입니다.

```python
def hello_world():
    print("Hello, world!")

hello_world()
```

### 결론

위 규칙들을 따르면 문서를 더욱 효과적으로 편집할 수 있습니다. **마크다운**은 강력한 도구입니다.
