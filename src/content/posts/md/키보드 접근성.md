
## tabIndex={}
포커스 순서를 제어하는 속성

| 값             | 동작                                                       |
| :------------ | :------------------------------------------------------- |
| tabIndex={0}  | 기본 포커스 순서에 포함. 원래 포커스가 안 되는 요소(div, span 등)도 포커스 가능하게 만듦 |
| tabIndex={-1} | Tab으로는 접근 불가, JS(element.focus())로만 포커스 가능               |
| tabIndex={1+} | 양수값 순서대로 먼저 포커스됨. 사용 비권장                                 |

## aria-labelledby

```
aria-labelledby={속성} 
```

이는 해당 속성을 id 로 가진 요소의 텍스트를 읽어주는 속성
