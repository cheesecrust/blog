## PR #567 — [KOMI-2541] 정렬 드롭다운 키보드 접근성 추가

**상태**: Open (Approved)
**변경**: +230 / -25
**Jira**: KOMI-2541

### 주요 변경 사항

정렬 드롭다운(추천순/툴콜순/최신순)을 키보드만으로 조작할 수 있도록 WAI-ARIA Listbox 패턴을 구현했다.

**`useDropdown` 훅 신규 생성** — 드롭다운의 열기/닫기, 포커스 관리, 키보드 네비게이션을 캡슐화한 범용 훅이다. 버튼 props(`aria-expanded`, `aria-haspopup`, `aria-controls`), listbox props(`role="listbox"`, `aria-activedescendant`), option props(`role="option"`, `aria-selected`)를 반환하여 컴포넌트에서 스프레드하는 방식으로 사용한다.

키보드 동작:
- `ArrowDown`/`ArrowUp` — 옵션 이동 (경계에서 순환하지 않음)
- `Enter`/`Space` — 선택
- `Escape`/`Tab` — 닫기 후 트리거 버튼으로 포커스 복귀
- `Home`/`End` — 처음/마지막으로 이동

**Sort 컴포넌트 리팩토링** — 기존 `useState`로 관리하던 open/close 로직을 `useDropdown` 훅으로 대체했다. `SortItem`도 `button` 기반에서 `li[role="option"]`으로 변경하여 listbox 패턴에 맞게 수정했다.

**오늘 커밋**:
- `3c14b84` refactor: preventDefault 위치 조정 — Escape/Tab 키 처리 시 `preventDefault`가 불필요하게 호출되던 것을 수정. Tab 키에서 `preventDefault`를 제거하여 자연스러운 포커스 이동이 가능하도록 했다.

### 변경된 파일

- `src/hooks/useDropdown.ts` — 드롭다운 키보드 네비게이션 및 ARIA 속성을 관리하는 범용 훅 (신규)
- `src/types/dropdown.ts` — 드롭다운 props 타입 정의 (신규)
- `src/components/home/Sort.tsx` — useState 기반 → useDropdown 훅 기반으로 리팩토링, listbox ARIA 속성 추가

## PR #568 — [KOMI-2560] 홈 화면 뒤로가기 시 포커스 복원 기능 추가

**상태**: Open
**변경**: +269 / -9
**Jira**: KOMI-2560

### 주요 변경 사항

홈 화면에서 MCP 카드나 페이지네이션 버튼을 클릭한 후 뒤로가기 했을 때, 이전에 포커스되어 있던 요소로 자동 복원되는 기능을 추가했다.

**`useFocusRestore` 훅 신규 생성** — 핵심 메커니즘:
- **포커스 저장**: `focusin` 이벤트를 감지하여 현재 포커스된 요소의 `data-focus-id`를 `sessionStorage`에 location key별로 저장
- **포커스 복원**: `navigationType === 'POP'`(뒤로가기)일 때 저장된 ID로 요소를 찾아 포커스
- **비동기 대응**: 요소가 아직 렌더링되지 않았을 수 있으므로 `MutationObserver`로 DOM 변화를 관찰하며 최대 500ms 대기
- **취소 처리**: 사용자가 키보드/마우스 입력을 하면 자동 복원을 취소

초기에는 렌더링 순서 기반 ID를 사용했으나, 리뷰 피드백을 통해 데이터 변동 시 문제가 발생할 수 있다는 점을 인식하고 **의미 기반 고유 키**(mcpId, 페이지 번호)로 변경했다.

**오늘 활동**:
- aiden-dw로부터 리뷰 코멘트 수신 (focusProps/useFocusId 헬퍼 제거 후 data-focus-id 직접 사용 방식에 대한 피드백)

### 변경된 파일

- `src/hooks/useFocusRestore.ts` — 포커스 저장/복원 훅 (신규)
- `src/components/home/McpItem.tsx` — `data-focus-id={mcp-list-${mcp.id}}` 추가
- `src/components/home/McpList.tsx` — 목록 컨테이너에 `tabIndex={-1}`, `role="region"`, `aria-label` 추가
- `src/components/layout/Pagination.tsx` — 이전/다음/페이지 번호 버튼에 `data-focus-id` 추가
- `src/components/layout/GlobalLayout.tsx` — `useFocusRestore()` 전역 등록
- `src/styles/playMcp/css/focus-visible.css` — `.list_aitool:focus` 아웃라인 제거
- `e2e/scroll-restore.spec.ts` — 카드/페이지네이션 포커스 복원 E2E 테스트 (신규)
- `e2e/focus-restore-benchmark.spec.ts` — 포커스 복원 성능 벤치마크 100회 (신규)

## PR #570 — [KOMI-2608] Dialog 키보드 접근성 개선

**상태**: Open
**변경**: +82 / -3
**Jira**: KOMI-2608

### 주요 변경 사항

Dialog 컴포넌트에 focus trap을 적용하여 모달이 열렸을 때 Tab 키로 포커스가 바깥으로 빠져나가지 않도록 했다.

**`useFocusTrap` 훅 신규 생성** — Dialog가 열리면:
1. 이전 포커스 위치를 `previousFocusRef`에 저장
2. Dialog 내부 첫 번째 focusable 요소에 자동 포커스
3. Tab/Shift+Tab으로 마지막↔첫 번째 요소 간 순환
4. Dialog 닫히면 원래 포커스 위치로 복원

**Dialog 컴포넌트 WAI-ARIA 속성 추가**:
- `aria-modal="true"` — 스크린리더에 모달임을 알림
- `aria-labelledby={DIALOG_TITLE_ID}` — 제목과 연결
- `tabIndex={-1}` — 프로그래밍 방식 포커스 가능
- `layer_body`에 `tabIndex={0}` — 본문 영역 키보드 포커스 가능

### 변경된 파일

- `src/hooks/useFocusTrap.ts` — focus trap 훅 (신규)
- `src/components/layout/Dialog.tsx` — focus trap 적용, ARIA 속성 추가
- `src/styles/playMcp/css/focus-visible.css` — `.layer_body` 포커스 스타일 추가
